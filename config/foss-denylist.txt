# Maven group prefixes that must never appear on a shipped classpath,
# directly or transitively. One prefix per line; a prefix matches the group
# itself and any sub-group (com.google.firebase matches com.google.firebase.foo).
#
# These are here because they are proprietary, or need proprietary Google
# services at runtime, or are trackers/crash reporters. F-Droid rejects them,
# and Nagwatch promises none of them. Licence problems are caught separately
# by Licensee; this list catches artifacts whose licence looks fine but whose
# behaviour is not.
#
# Adding to this list needs no discussion. Removing from it does.
