# App is "Nagwatch", applicationId net.pgmac.nagwatch

"Nagios" is a registered trademark of Nagios Enterprises, so the published app name avoids it; the repo is `nagios-android` for discoverability and the store tagline describes compatibility only. The `applicationId` is `net.pgmac.nagwatch` (the maintainer owns `pgmac.net`). Changing an `applicationId` after release creates a different app, so existing installs would not upgrade; the repo name is cheap to change, the id is not. Name check on 2026-10-08 (web search only): no Android, Google Play or F-Droid app called Nagwatch found. Older Nagios-ecosystem tools share the name on other platforms (the Windows NagWatch32 from 2009, and the original GTK/perl `nagwatch`), so the name is not unique in the ecosystem, only on Android. Accepted as low risk. A direct Play Store / F-Droid lookup of the final id must be repeated before the first release (M7).
