# License the app GPL-3.0-or-later

Nagwatch is an end-user app, not a library, so permissive licensing buys little: nobody embeds an app. Copyleft stops closed or ad-laden reskins of the same code on app stores, and is accepted by F-Droid. Rejected: MIT (matches other pgmac-net repos but allows closed forks), Apache-2.0 (patent grant, same closed-fork gap). Relicensing later would need agreement from every contributor, so the choice is effectively permanent once outside contributions land. Nagios' own GPL-2.0 is not a factor: the app only speaks HTTP to it and links none of its code.
